## 一、美国VPS测评到底在测什么？先看清这五把尺子

很多人买美国 VPS 翻车，不是因为商家坑，而是因为压根没看懂测评数据。这里先把"测评维度"这件事讲明白，后面 Evoxt 的部分你才看得进去。

**延迟（Latency / Ping）**

美国机房到国内，物理距离摆在那儿，光速都救不回来。一般规律是：美西洛杉矶到上海 CN2 GIA 线路能压到 130ms 左右，普通直连 180–220ms，晚高峰可能飙到 250ms+。Evoxt 美国机房属于标准线路（Standard），第三方实测国内延迟大致在 170–230ms 区间，属于"能跑建站、跑代理够呛"的水平。

**丢包率（Packet Loss）**

延迟高不可怕，可怕的是丢包。一个 200ms 但 0 丢包的机器，比 150ms 但晚高峰丢 15% 的机器好用一万倍。看测评时盯死晚高峰（北京时间 20:00–23:00）的丢包曲线，这是大部分廉价美国 VPS 翻车的重灾区。

**带宽与月流量**

注意区分两个概念：**端口速率**（1Gbps 端口）和**实际可用带宽**。Evoxt 全机房 1Gbps 端口，标准线路套餐按月给流量配额，从 500GB 到 10TB 不等，超出后按 $3/TB 计费。这点比那些"无限流量但偷偷限速"的商家实在。

**路由质量（去程 / 回程）**

去程是你访问机器走的路，回程是机器把数据送回国内走的路。**对国内用户来说，回程比去程更关键**，因为网页加载、文件下载主要看回程。CN2 GIA、AS9929、CU 4837 这些都是回程优化线路的代号，标准直连线路则要看运营商互联互通情况。

**CPU 单核性能**

这点很多人忽略。VPS 跑 WordPress、跑小爬虫、跑代理，**单核主频比核数重要得多**。Evoxt 主打的就是高频 CPU，官网宣称最高 6.0 GHz Turbo Clock，这点是它的核心卖点，后面会专门讲。
